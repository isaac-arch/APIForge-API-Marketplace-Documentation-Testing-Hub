# APIForge

## Overview
APIForge is a centralized API marketplace that allows developers to discover, document, and test APIs from a single platform.

## Requirements
- XAMPP
- PHP 8+
- MySQL

## Setup
1. Copy project to htdocs/apiforge
2. Start Apache & MySQL
3. Import database.sql via phpMyAdmin
4. Open http://localhost/apiforge

## Usage
- Register as developer
- Publish APIs
- Browse APIs
- Test endpoints
- Generate API keys

## Admin
Set user role to admin in database and access /admin/dashboard.php

## Security
- Password hashing
- API key generation
- Request logging ready
